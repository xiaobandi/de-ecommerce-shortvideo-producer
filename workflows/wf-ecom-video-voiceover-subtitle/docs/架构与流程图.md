# 口播文案+字幕 · 架构与流程图

## 本工作流的四层结构

```mermaid
flowchart TB
  U["使用层：短视频/直播内容 的使用者"]
  T["触发层：口播文案+字幕"]
  X["执行层：3 个步骤"]
  O["产出层：字幕文件"]
  U --> T --> X --> O
```

| 层 | 内容 |
|---|---|
| 使用层 | 周更 3 条以上内容的抖店/小红书卖家；员工定位：内容编导·小导 ｜ 不替你拍视频，只解决"今天拍什么、开头 3 秒说什么、发完怎么复盘" |
| 触发层 | 关键词 / 显式点名「口播文案+字幕」；触发方式：人工 |
| 执行层 | 脚本 → 口播稿 → 字幕文件 |
| 产出层 | 字幕文件 |

flowchart LR
