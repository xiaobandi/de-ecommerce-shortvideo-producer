> ⚠️ 本技能尚未填写真实场景（`scenarios`），下面为**通用推导**，信息量有限。

## 场景一 · Listing/详情页文案的日常用法

- **角色**：Listing/详情页文案
- **触发时机**：需要「卖点提炼」这件事有结果的时候
- **他会说**：`用 sellingpoint-extract 帮我卖点提炼`
- **需要准备**：商品资料（参数 / 描述）
- **拿到什么**：FAB 卖点卡（特性 / 优势 / 利益）
- **容易踩的坑**：纯参数罗列不是卖点——'500ml'是特性，'装够一天水量'才是卖点

---

## 场景二 · 换成你自己的材料

同一句话，把材料换成你手头的真实数据即可：

```text
用 sellingpoint-extract 处理下面这份材料：
<粘贴你的内容 / 贴文件路径>
```

**输入结构不要改**：字段名变了，脚本会读不到；缺字段时应当被明确告知缺什么，而不是猜。

| 字段 | 必填 | 说明 |
|---|---|---|
| 商品资料（参数 / 描述） | ✅ | 缺失会导致输出不可用 |
| 目标人群 | ⬜ | 有则更好 |
| 竞品对照 | ⬜ | 有则更好 |
| 买家评论 | ⬜ | 有则更好 |

---

## 场景三 · 接进自动化链路

脚本是纯函数（文件进 / stdout 出 / 退出码表达判定），可以直接被 CI、定时任务调用：

```bash
python3 scripts/sellingpoint_extract.py --file examples/input/product.json
```

| 退出码 | 含义 | 链路里应该怎么做 |
|---|---|---|
| 0 | 通过 | 继续下一步 |
| 1 | 警告 | 记入待办，不阻塞 |
| 2 | 阻断 | **中断流程**并转人工 |
