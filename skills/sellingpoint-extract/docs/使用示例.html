使用示例

技能：卖点提炼（sellingpoint-extract）

⚠️ 本技能的真实效果示例尚未补齐：以下仅为输入 / 输出契约（不构成效果证据）与平台兼容性验证结果。发布前须补至少 3 组「真实输入 → 实际产出」。

示例一 · 标准用法（真实运行）

python3 scripts/sellingpoint_extract.py --file examples/input/product.json

真实输出：

商品：真空保温杯　目标人群：通勤人群

1. 特性　容量：500ml
   优势　容量为 500ml
   利益方向　省事（少续装）
   所需证据　需明确容量口径：满杯 / 有效容量
2. 特性　保温：24 小时
   优势　保温为 24 小时
   利益方向　省事（少反复加热）
   所需证据　需实测保温时长与测试条件
3. 特性　重量：280g
   优势　重量为 280g
   利益方向　便携（更轻）
   所需证据　需给出实测重量与称量口径
4. 特性　材质：304 不锈钢
   优势　材质为 304 不锈钢
   利益方向　安心（接触体验）
   所需证据　涉及接触安全，需食品级资质或检测报告后才可对外声称

⚠ 以下卖点只有方向、无可发布文案，需补证据后撰写：容量：500ml, 保温：24 小时, 重量：280g, 材质：304 不锈钢
参数被翻译成 FAB（特性 → 优势 → 利益），用户看得懂才算卖点
注意：参数不等于卖点：『304 不锈钢』是特性，『不生锈不串味』才是用户利益。

示例二 · 用你自己的材料

python3 scripts/sellingpoint_extract.py --file /path/to/your-data/product.json

把 examples/input/ 下的文件换成你的真实材料即可；输入结构不要改，改了字段名脚本会读不到。

示例三 · 嵌进自动化链路

set -e
python3 scripts/sellingpoint_extract.py --file examples/input/product.json || exit 2   # 非零即阻断

脚本是纯函数：文件/stdin 进、stdout 出、退出码表达判定，因此可以被 CI、定时任务或上层工作流直接编排。

质量自检（交付前必过）

  • [ ] 每条卖点有明确利益点，非纯参数复述
  • [ ] 参数原值引用，未四舍五入
